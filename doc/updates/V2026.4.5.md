# 📦 RPClient 2026.4.5

### 中文版本 (Chinese)

#### ✨ 新增功能

- **Gemini Interactions v1 协议支持：**
  - 新增独立的 **Gemini Interactions** 协议与模型预设，支持模型列表拉取、分页及连接测试，与原有 Gemini GenerateContent 配置互不影响。
  - 基于本地历史构建无状态请求，支持文本与图片输入、流式/非流式输出、取消生成及 Token 用量统计。
- **#37 群聊对话分支：**
  - 群聊消息操作栏新增“从这里分支”，可将截至所选消息的历史记录、成员配置、图片附件与有效摘要完整复制到独立新群聊，不影响原会话。
- **角色卡 PNG / JSON 导出与混合导入：**
  - 导出角色卡时支持按头像配置选择 PNG 或 JSON 格式；PNG 使用原始头像并嵌入 SillyTavern 兼容元数据，批量导出时无头像项自动回退为 JSON。
  - 角色导入支持包含 PNG 与 JSON 混合内容的 ZIP 归档，并自动恢复角色头像。
- **生成失败弹窗与流式中断原位重试：**
  - 统一单聊与群聊的生成失败提示弹窗，按配置异常、瞬时故障或附件限制提供对应操作引导。
  - 流式回复中途失败支持原位重试，自动保留当前上下文，并避免被世界书同轮冷却误拦截。
- **设置页显式保存与摘要逐版恢复：**
  - 单聊设置调整为显式保存，与群聊、故事设置统一在存在未保存修改离开时弹出确认（保存 / 放弃 / 取消）。
  - 单聊与群聊的手动摘要、分批重做与历史恢复统一纳入设置草稿，支持先撤销手工编辑、再逐版回退至历史摘要并还原对应消息覆盖位置；保存时完整保留本轮摘要历史，同时保留“立即摘要”快捷入口。
- **提示词预设扩展：**
  - 新增**角色描述格式**模板，单聊与群聊均按当前预设包装角色描述（群聊按角色归属展开宏）。
  - 新增 **Raw 摘要格式**自定义项，支持自定义已有摘要、聊天历史、单条消息与图片摘要模板，并自动校验必填占位符。
- **角色内容页多选与批量删除：**
  - 支持长按多选、按当前筛选结果全选/取消全选，并批量删除关联的单聊、群聊与故事；删除失败时保留未完成项供重试。
- **首次启动隐私与数据声明：**
  - 首次启动（含旧版本升级）展示隐私与数据声明，明确本地存储、无账号零遥测、第三方模型直连及本地模型后端的数据流向，并可在「设置 → 关于」随时回看。

#### 🎨 体验优化

- **提示词检查器改版：** 重构检查器界面，提供“消息 / 概览 / Regex”分标签视图、Token 预算与各角色占比统计、正文搜索、世界书/图片筛选与一键复制全部；新增独立阅读模式，支持按来源拆解、原文检索与字体切换。
- **提示词预设管理与编辑器优化：** 新增“仅看已改”筛选、分组已改计数、全部展开/折叠、只读横幅与实时必填宏校验；提示词编辑弹窗新增撤销与全屏编辑。
- **单聊与群聊消息界面统一：** 统一消息气泡、头像、思考块、外置操作栏与内联编辑样式，复用历史分页、搜索定位与滚动跟随行为。
- **创建页与设置页体验升级：** 优化单聊、群聊、故事创建页及会话设置页布局，引入统一的角色/世界书选择弹窗、已选摘要卡片与视口头像懒加载；创建提交期间禁用表单防止重复触发。
- **内容搜索页样式优化：** 改进搜索栏、范围/类型筛选条、结果卡片与进度叠加层，减少分页和检索状态切换时的界面跳动。

#### 🐛 问题修复

- **角色卡导入导出：**
  - 修复大体积 PNG 角色卡导出时可能内存溢出的问题（改为流式重写并限制 ZIP 条目大小），ZIP 头像导入改为磁盘暂存并在取消或失败时自动清理。
  - 修复角色导入异常时可能残留部分数据的问题（头像、世界书与角色原子提交），并补齐 PNG V3 角色卡的群聊开场白兼容性。
- **对话生成与历史：**
  - 修复被摘要覆盖的末条原始提问或图片在重生成、群聊无新输入接话时丢失的问题，补齐空历史重生成边界。
  - 修复群聊恢复时覆盖流式正文、续写/重生成未及时进入生成态，以及分支历史在相同时间戳下截断异常或界面重建丢失跳转的问题。
- **摘要与会话设置：**
  - 修复单聊摘要聚焦时被旧草稿覆盖、群聊重复点击摘要无效加载及未校验专用摘要模型的问题。
  - 修复作者备注清空后未恢复角色默认继承、已删除人设未刷新草稿、保存失败丢失成员/世界书选择，以及摘要取消后状态未复位的问题；补齐单聊设置的世界书搜索入口与备注继承预览。
- **Gemini 协议与模型配置：**
  - 修复 Gemini Interactions 返回不完整回复（`incomplete`）时丢失已生成正文的问题，并在摘要流程中拦截不完整结果，避免覆盖原有记忆。
  - 修复空白 SSE 帧、提前断流、纯系统提示输入及错误码分类问题；切换或重选 Gemini 协议时保留有效配置并自动转换默认请求体补丁。
  - 修复模型配置卡片次行标签在窄屏下宽度异常或被裁切的问题。
- **界面与搜索：**
  - 修复角色列表点击返回后残留高亮、世界书编辑页长标题显示不全（改为单行跑马灯）、预设分组已改计数分母与角色内容页全选判断偏差。
  - 修复搜索切换与过期查询污染结果缓存的问题，恢复已启用世界书的条目搜索并隔离搜索折叠状态。
  - 修复故事创建页默认主角顺序与已有角色激活模式可能被覆盖的问题。

#### ℹ️ 使用说明与注意事项

- **Gemini Interactions 协议：** 采用本地历史构建的无状态请求，与 Gemini GenerateContent 配置相互独立且均支持完整备份与恢复；暂不包含服务端会话续传与思考签名回传。
- **显式保存与摘要草稿：** 单聊设置已改为显式保存，手动摘要、重做与历史恢复均先暂存为草稿，保存后生效；自动摘要继续即时持久化。
- **角色卡导出与归档限额：** PNG 导出保留原始头像与 SillyTavern 兼容元数据，批量导出时无头像角色自动回退为 JSON；角色 ZIP 沿用既有条目数与容量限额。
- **隐私与数据声明：** 升级至本版本后首次启动会展示一次隐私与数据声明，后续可随时在「设置 → 关于」中再次查看。

### English Version (英文)

#### ✨ What's New

- **Gemini Interactions v1 Protocol Support:**
  - Added a dedicated **Gemini Interactions** protocol and model preset with paginated model catalog listing and connection testing, independent of existing Gemini GenerateContent configurations.
  - Builds stateless requests from local history with support for text and image input, streaming and non-streaming output, cancellation, and Token usage reporting.
- **#37 Group Chat Branching:**
  - Added **Branch from here** to the group chat message action bar, copying history up to the selected message along with members, settings, image attachments, and valid summaries into an independent new group chat.
- **Character Card PNG / JSON Export and Mixed ZIP Import:**
  - Single and bulk character exports now support choosing between PNG and JSON based on avatar availability. PNG exports embed SillyTavern-compatible metadata into the original avatar; characters without avatars fall back to JSON during bulk export.
  - Character import now accepts mixed PNG/JSON ZIP archives and restores embedded avatars automatically.
- **Unified Failure Dialogs and In-Place Streaming Retry:**
  - Unified generation failure dialogs across single and group chats with tailored guidance for configuration issues, transient errors, and attachment limits.
  - Interrupted streaming replies can now be retried in place while preserving context and avoiding false World Book same-turn cooldown blocks.
- **Explicit Settings Save and Versioned Summary Recovery:**
  - Single-chat settings now use explicit saving, matching group-chat and story settings with a unified Save / Discard / Cancel confirmation when leaving with unsaved edits.
  - Manual summaries, batched redos, and summary history recovery in single and group chats are unified as settings drafts. Undo manual edits first, then step back through prior versions with accurate message coverage restoration. Explicit save preserves the full session summary history while keeping the quick summarize shortcut.
- **Prompt Preset Extensions:**
  - Added a customizable **Character Description Format** template for single and group chats (with per-character macro resolution in group chats).
  - Added customizable **Raw Summary Format** templates for existing summaries, chat history, individual messages, and image summary instructions, with automatic required-placeholder validation.
- **Multi-Select and Bulk Delete on Character Content Pages:**
  - Long-press to multi-select, select or deselect all filtered results, and bulk-delete associated single chats, group chats, and stories. Failed items remain selected for retry.
- **First-Launch Privacy & Data Notice:**
  - Displays a one-time Privacy & Data Notice on first launch (including upgrades), explaining local-only storage, zero telemetry, direct third-party provider connections, and local model backends. Available anytime in **Settings → About**.

#### 🎨 Improvements

- **Redesigned Prompt Inspector:** Rebuilt with Messages / Overview / Regex tabs, Token budget and per-role breakdown, search, World Book and image filters, and copy-all support. Added a dedicated reader view with source-segment breakdown, in-message search, and font switching.
- **Prompt Preset Manager & Editor:** Added an "Only customized" filter, per-group customized counts, expand/collapse all, read-only indicators, and live required-macro validation. The prompt editor dialog now supports undo and fullscreen editing.
- **Unified Single & Group Chat Messaging UI:** Standardized message bubbles, avatars, reasoning blocks, external action bars, and inline editing across single and group chats, sharing history pagination, search jump, and scroll behavior.
- **Creation & Settings Flows:** Refined single-chat, group-chat, and story creation and settings layouts with unified character and World Book picker dialogs, selection summary cards, viewport-scoped avatar loading, and form locking during submission.
- **Content Search UI:** Improved the search bar, scope/type filter bar, result cards, and progress overlay to reduce layout jumps during pagination and query transitions.

#### 🐛 Bug Fixes

- **Character Card Import & Export:**
  - Fixed potential out-of-memory crashes when exporting large PNG character cards by streaming PNG rewrites and enforcing ZIP entry limits; ZIP avatars are now staged on disk and cleaned up on cancel or failure.
  - Fixed partial data persistence on failed character imports by committing avatars, World Books, and characters atomically, and improved PNG V3 group-greeting compatibility.
- **Chat Generation & History:**
  - Fixed the latest summarized prompt or image being dropped during regeneration or no-input group continuations, and handled empty-history regeneration edge cases.
  - Fixed group-chat resume overwriting streaming output, delayed generation state on continuation/regeneration, branch truncation errors on identical timestamps, and lost branch navigation across UI recreation.
- **Summaries & Session Settings:**
  - Fixed single-chat summaries being overwritten by stale drafts while focused, no-op reloads on repeated group-chat summary taps, and missing summary-model validation.
  - Fixed cleared creator notes failing to restore character inheritance, stale drafts after persona deletion, lost member/World Book selections on save failure, and missing state resets after summary cancellation. Added World Book search and creator-note inheritance preview to single-chat settings.
- **Gemini Protocol & Provider Configuration:**
  - Fixed Gemini Interactions discarding partial text on `incomplete` responses while blocking incomplete results from overwriting existing summaries.
  - Fixed blank SSE frames, premature stream termination, system-only inputs, and error-code classification; switching or reselecting Gemini protocols preserves valid settings and converts default request-body patches.
  - Fixed secondary tag width and clipping on provider cards on narrow screens.
- **UI & Search:**
  - Fixed lingering selection highlights when returning to the character list, truncated long World Book titles (now single-line marquee), preset customized-count denominators, and select-all state on character content pages.
  - Fixed stale search queries polluting or clearing fresh results, restored entry search for enabled World Books, and isolated search collapse states.
  - Fixed default protagonist ordering and existing character activation modes being overwritten on the story creation page.

#### ℹ️ Notes and Precautions

- **Gemini Interactions Protocol:** Uses stateless requests built from local history and operates independently of Gemini GenerateContent configurations (both are included in full backups and restores). Server-side session continuation and thought-signature round-tripping are not included yet.
- **Explicit Save & Summary Drafts:** Single-chat settings now require explicit saving. Manual summaries, redos, and restored history stay as drafts until saved; automatic summaries continue to persist immediately.
- **Character Card Exports & Archive Limits:** PNG exports retain original avatars and SillyTavern-compatible metadata, with avatarless cards falling back to JSON in bulk exports. Character ZIP archives keep the existing entry and size limits.
- **Privacy & Data Notice:** Shown once on first launch after updating and accessible anytime under **Settings → About**.
