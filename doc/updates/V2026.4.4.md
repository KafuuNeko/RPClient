# 📦 RPClient 2026.4.4

### 中文版本 (Chinese)

#### ✨ 新增功能

- **多用户人设管理：**
  - 设置页支持创建、切换、编辑和删除多套用户人设，分别保存名称、描述与头像，并选择默认人设。
  - 创建及编辑单聊、群聊时可选择具体人设或“跟随默认人设”。新聊天固定创建时的发言名；名称与描述支持分别覆盖，清空对应字段即可恢复继承。
  - 故事可独立选择人设，也可选择“不注入用户人设”。群聊历史保留发送时的发言者署名，切换人设不会改写已有消息。
  - 删除人设后，关联聊天保留原发言名并改为跟随默认人设，关联故事停止注入该人设；删除最后一套时自动创建默认的 `You`。
- **自定义提示词预设：**
  - 新增预设管理页，支持搜索、新建、复制、修改名称与简介、启用和删除，整套切换单聊、群聊、故事及摘要使用的提示词。
  - 系统默认预设保持只读，可复制后自定义；自定义预设仅覆盖修改过的项目，其余项目继续使用系统默认值。
  - 编辑页按基础指令、生成辅助、摘要与记忆、格式与分隔符分组，支持按单聊、群聊或故事筛选，并区分默认、自定义及空内容状态。
  - 提示词编辑器提供宏插入、恢复默认、复制及字符与 Token 统计，离开未保存的编辑时提示确认。
- **世界书批量导入、导出与多选删除：**
  - 世界书导入支持一次选择多个文件及读取 ZIP，展示读取、保存进度，并汇总成功与失败数量；损坏的单本不会阻断其他有效世界书。
  - 对低固定 Token 预算的世界书统一询问一次，可选择保留原预算或改为跟随全局预算。
  - 世界书列表支持长按多选、按筛选结果全选或取消全选，并将所选世界书导出为 ZIP，包内为可独立导入的 SillyTavern 兼容 JSON；导出先在缓存完成打包与限额检查，再写入目标文件。
  - 角色卡、世界书及世界书条目支持多选批量删除。删除有关联对话的角色时增加二次确认；批量删除角色保留关联世界书。
- **#28 用户代写与群聊扮演用户：**
  - 单聊“扮演用户”支持将结果写入输入框，续写已有草稿，生成后可继续编辑并自行发送；仍可选择直接写入聊天记录。
  - 群聊新增“扮演用户”，同样支持聊天记录与输入框两种输出方式，使用当前群聊的用户人设。
  - 输入框代写支持流式显示、独立查看思考内容和停止生成，取消或失败时保留原草稿及已生成正文。
  - 单聊与群聊分别提供扮演用户、输入框续写的独立提示词；续写模板支持用 `{{draft}}` 放置草稿，空白输入只使用扮演用户指令。
- **摘要模式与 SillyTavern 摘要互通：**
  - 单聊与群聊可在全局设置中选择 Raw（增量）或 Classic（当前上下文）摘要模式。Raw 顺序处理尚未总结的历史，Classic 基于当前可容纳的近期上下文更新记忆。
  - 单聊 JSONL 导入与导出支持 SillyTavern 的消息摘要及覆盖位置，重新导入时识别在酒馆中修改或清除的摘要，并继续兼容旧版 RPClient 归档。
- **模型级图片画质与 Token 预估：**
  - 模型编辑页新增图片画质设置，按模型和协议提供自动、低、中、高、原始细节或超高等适用档位，请求编码与本地预算使用同一配置。
  - 扩展 OpenAI、Claude 与 Gemini 的图片预估规则，补充新型号、日期快照与常见路由别名，并结合图片尺寸及画质计算开销。
  - 未知模型改用带最低预留的面积估算，减少大图开销被固定回退值低估的情况；未知规则、跨模型手选类别等结果明确标记为估算。
- **#34 群聊与故事管理入口：**
  - 群聊设置将操作区置顶，补充续写、重新生成最新回复及扮演用户入口；重新生成成功后原位替换回复，失败或取消时保留原文。
  - 故事设置新增整篇删除入口与确认，删除完成后退出编辑器。

#### 🎨 体验优化

- **设置与编辑界面：**
  - 精简设置页的重复说明，将提示词后处理、示例对白和摘要等选项整理为更紧凑的下拉选择与分区。
  - 统一单聊与群聊输入区的圆角、字号、描边、快捷操作间距及发送按钮对齐，协调群聊和故事设置的输入框、分区与模型配置提示样式。
  - 调整加载弹窗的动画、文字与取消按钮，统一群聊加载、保存、删除及创建过程的进度展示。
- **页面加载与摘要操作：**
  - 统一单聊与群聊的初始加载页，提前应用所属页面及角色背景，减少进入页面时的黑闪与背景跳变。
  - 群聊手动摘要支持取消和重试，完成后保留其他尚未保存的设置草稿。
- **提示词与宏：**
  - 统一单聊、群聊、故事与摘要的宏解析，支持嵌套引用并检测循环引用及展开超限。
  - 优化默认场景、性格、人设、摘要与故事记忆模板，使用明确的内容分区，并在场景和性格中标明对应角色。

#### 🐛 问题修复

- 修复 Claude 接口地址已带 `/v1` 时重复拼接版本路径、导致请求失败的问题，兼容根地址与版本化地址。
- 修复 Claude 缓存写入被计入缓存命中，以及流式响应 Token 总量未随输出更新的问题；用量页分别展示缓存读取与写入明细。
- 修复群聊中角色资料、示例对白、世界书及正则脚本的宏使用错误角色信息的问题，按内容所属角色及历史发言者解析，改善世界书扫描与递归触发的一致性。
- 修复关闭“跟随通用设置”后，清空单聊、群聊或故事背景仍回退到通用图片的问题；独立页面完整使用自身图片与外观参数。
- 修复返回外观页或应用背景设置后，列表滚动位置被重置的问题。
- **#33** 修复预设及系统动态深色配色下，故事正文、聊天气泡与次级控件层次不清的问题。
- 修复输入框描边、底板与分隔线的透明度计算不一致，导致栏位外观与设置值不符的问题。
- 修复整数设置在逐位输入时过早应用约束、影响清空重填的问题，改为在失焦、完成或离开设置项时提交；改善代码编辑弹窗的长文本滚动及光标跟随。
- 修复高级请求 JSON 格式化、保存时丢失显式 `null` 的问题，保留删除请求字段的原有语义。
- 移除主数据库降级时自动清库重建的处理，缺少迁移路径时拒绝打开并保留原数据。

#### ℹ️ 使用说明与注意事项

- 升级时，旧用户名称、描述与头像自动迁入人设库，已有聊天保留原发言名。旧版已保存的提示词迁入并启用“自定义预设1”；没有旧提示词保存记录时使用系统默认。新建或复制预设后需在管理页手动启用。
- 完整备份继续使用 v3，并保存人设库、会话人设绑定、提示词预设及当前选择；旧备份仍按归档自带设置完成迁移。备份与恢复仍为试验性功能，恢复会替换现有数据，请先保留备份并参阅[完整数据备份与恢复说明](../archive/manual-backup-restore.md)。
- 摘要模式默认沿用 Raw。Classic 面向当前上下文，可能越过因预算不足被裁剪的早期消息，不保证逐条总结全部历史；该选择适用于单聊与群聊。
- 世界书 ZIP 最多 1,000 个归档条目、64 MiB 压缩数据，包内单个 JSON 最多 8 MiB；独立 JSON 最多 32 MiB。单次导入或批量导出累计 JSON 最多 32 MiB，每本最多 16,384 条世界书条目、累计最多 32,768 条，并受结构复杂度限制。超限时请拆分文件、减少所选世界书或缩小内容。
- 模型图片画质控制请求端的图片理解参数，不会修改已保存的图片，也不替代发送图片时的压缩设置。“自动”沿用既有模型设置；本地图片 Token 仍属预估，实际用量以服务商返回为准。

### English Version (英文)

#### ✨ What's New

- **Multiple User Personas:**
  - Create, switch, edit, and delete user personas in Settings. Each persona has its own name, description, and avatar, with a selectable default.
  - Choose a specific persona or Follow Default Persona when creating or editing single and group chats. New chats retain their creation-time speaker name. Override the name and description separately, or clear either field to inherit it again.
  - Stories can select a persona independently or omit personas entirely. Group-chat history retains the speaker names recorded when messages were sent; switching personas does not rewrite existing messages.
  - Deleting a persona keeps associated chats' speaker names and makes them follow the default persona. Associated stories stop including that persona. Deleting the last persona creates a fresh default named `You`.
- **Custom Prompt Presets:**
  - A new preset manager supports search, creation, copying, name and description editing, activation, and deletion. Switch a complete set of prompts for single chats, group chats, stories, and summaries.
  - The system default is read-only and can be copied for customization. Custom presets override edited items while other items continue using system defaults.
  - The editor groups prompts into core instructions, generation assistance, summaries and memory, and formats and separators. Filter by single chat, group chat, or story, with distinct indicators for default, custom, and empty content.
  - The prompt editor offers macro insertion, reset to default, copying, character and Token counts, and confirmation before discarding unsaved edits.
- **Bulk World Book Import, Export, and Deletion:**
  - Import multiple files or ZIP archives, with reading and saving progress and successful and failed import counts. A damaged individual World Book does not block other valid books.
  - A single confirmation covers books with low fixed Token budgets, allowing you to keep their original budgets or use the global budget.
  - Long-press to select World Books, select or deselect all filtered results, and export selected books as a ZIP containing individually importable SillyTavern-compatible JSON files. Packaging and limit checks finish in cache before writing the destination.
  - Bulk deletion is available for character cards, World Books, and World Book entries. Deleting characters with associated conversations requires a second confirmation. Bulk character deletion keeps bound World Books.
- **#28 User Writing and Group-Chat Impersonation:**
  - Single-chat Impersonate User can now write into the input box and continue an existing draft, letting you edit and send it yourself. Direct output to chat history remains available.
  - Group chats now support Impersonate User with the same chat-history and input-box output choices, using the current group-chat persona.
  - Input-box writing supports streaming, separate reasoning display, and stopping generation. Cancellation or failure preserves the original draft and any generated body text.
  - Single and group chats have separate impersonation and draft-continuation prompts. Use `{{draft}}` to place a draft in the continuation template; blank input uses only the impersonation instruction.
- **Summary Modes and SillyTavern Summary Compatibility:**
  - Choose Raw (incremental) or Classic (current context) in global settings for single and group chats. Raw processes unsummarized history in order; Classic updates memory from recent context that fits the budget.
  - Single-chat JSONL import and export now support SillyTavern message summaries and their coverage positions. Reimport recognizes summaries edited or cleared in SillyTavern while retaining compatibility with older RPClient archives.
- **Per-Model Image Quality and Token Estimation:**
  - Model editing now offers applicable Auto, Low, Medium, High, Original Detail, or Ultra High image quality options according to the model and protocol. Request encoding and local budgeting use the same configuration.
  - Expanded image estimation rules for OpenAI, Claude, and Gemini, including newer models, dated snapshots, and common routing aliases. Estimates account for image dimensions and quality.
  - Unknown models use an area-based estimate with a minimum reserve, reducing underestimation of large images from a fixed fallback. Unknown rules and manually selected estimators for a different model are clearly marked as estimates.
- **#34 Group-Chat and Story Management:**
  - Group-chat settings place actions first and add entries for continuation, regenerating the latest reply, and impersonation. Successful regeneration replaces the reply in place; failure or cancellation preserves the original.
  - Story settings now include whole-story deletion with confirmation, closing the editor after deletion.

#### 🎨 Improvements

- **Settings and Editors:**
  - Reduced repeated descriptions and organized prompt post-processing, example-dialogue, and summary options into more compact dropdowns and sections.
  - Unified single- and group-chat input corners, typography, borders, shortcut spacing, and send-button alignment. Coordinated input fields, sections, and model-configuration notices across group-chat and story settings.
  - Refined loading-dialog animation, text, and cancellation controls, with consistent progress displays for group-chat loading, saving, deletion, and creation.
- **Page Loading and Summary Actions:**
  - Unified initial loading pages for single and group chats, applying the relevant page or character background earlier to reduce black flashes and background changes on entry.
  - Manual group summaries support cancellation and retry, preserving other unsaved settings drafts after completion.
- **Prompts and Macros:**
  - Unified macro resolution across single chats, group chats, stories, and summaries, with nested references, cycle detection, and expansion limits.
  - Refined default scenario, personality, persona, summary, and story-memory templates with explicit content sections and character labels for scenarios and personalities.

#### 🐛 Bug Fixes

- Fixed duplicate version paths causing Claude requests to fail when the endpoint already contains `/v1`. Both root and versioned endpoints are supported.
- Fixed Claude cache writes being counted as cache hits and streaming Token totals failing to update with output. Usage details now show cache reads and writes separately.
- Fixed group-chat macros using the wrong character information in character definitions, example dialogue, World Books, and Regex scripts. Resolution follows content ownership and historical speakers, improving consistency in World Book scanning and recursive activation.
- Fixed cleared single-chat, group-chat, or story backgrounds falling back to the general image after Follow General Settings was disabled. Independent pages now fully use their own images and appearance parameters.
- Fixed the appearance list losing its scroll position after returning or applying background settings.
- **#33** Fixed insufficient visual separation between story text, chat bubbles, and secondary controls in preset and system dynamic dark palettes.
- Fixed inconsistent opacity calculations for input borders, backgrounds, and dividers that made surface appearance differ from configured values.
- Fixed integer settings applying constraints during typing and interfering with clearing and reentry. Values commit on focus loss, Done, or leaving the setting. Improved long-text scrolling and cursor tracking in the code editor.
- Fixed explicit `null` values being lost when advanced request JSON was formatted or saved, preserving instructions to remove request fields.
- Removed automatic database clearing on downgrade. When no migration path exists, the primary database is preserved and opening is refused.

#### ℹ️ Notes and Precautions

- Upgrading migrates the previous user name, description, and avatar into the persona library while preserving existing chat speaker names. Previously saved prompts migrate into an active Custom Preset 1; installations without saved legacy prompts use system defaults. Newly created or copied presets must be activated manually in the manager.
- Full backups remain v3 and include personas, session persona bindings, prompt presets, and the active selection. Older backups migrate using their own archived settings. Backup and restore remains experimental and replaces existing data; retain a backup first and consult the [full backup and restore guide](../archive/manual-backup-restore.md).
- Raw remains the default summary mode. Classic targets the current context and may skip earlier messages removed by budget trimming, so it does not guarantee summarizing every historical message. This choice applies to single and group chats.
- World Book ZIP limits are 1,000 archive entries, 64 MiB compressed, and 8 MiB per contained JSON file. Standalone JSON files can be up to 32 MiB. Each import operation or bulk export is limited to 32 MiB of cumulative JSON and 32,768 World Book entries, with at most 16,384 entries per book, plus structural complexity limits. Split files, select fewer books, or reduce content when limits are exceeded.
- Model image quality controls request-side image-understanding parameters. It does not modify saved images or replace image-send compression settings. Auto retains existing model settings. Local image Token counts remain estimates; actual usage follows the provider's reported values.
