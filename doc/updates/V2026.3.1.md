# 📦 RPClient 2026.3.1

### 中文版本 (Chinese)

#### ✨ 新增功能

- **单聊与群聊图片消息：**
  - 支持发送图片、图文混合消息及纯图片消息，每条新消息最多可添加四张图片。
  - 新增图片查看器，支持缩放、双击、左右切换、缩略图导航与保存图片。
  - 提供自动、原图和自定义图片发送策略，可按需设置图片大小及宽高上限。
  - 支持通过 OpenAI-Compatible、Anthropic Messages 与 Gemini 协议发送图片，模型配置中可设置图片输入能力与 Token 估算策略。
  - 图片消耗纳入上下文与摘要预算，Prompt 检查器可查看图片相关信息及省略原因。
  - 用户消息编辑支持添加、删除和排序图片；导入的角色及旁白图片可保留、删除和排序，暂不开放添加入口。
- **聊天图片导入与导出：**
  - 单聊 JSONL 归档现可携带图片，导出后重新导入可恢复消息附件。
  - 支持导入 SillyTavern 的图片消息；遇到外部图片引用时，可选择本地资源目录匹配图片，缺失项会统计并跳过。
  - 图片归档支持压缩和重复资源去重，减少重复图片占用的文件空间。
  - 支持保留导入的角色及旁白图片，并在创建分支时一同复制。
- **Token 用量统计：**
  - 新增用量统计页面，展示输入、输出、总 Token 数和成功请求次数。
  - 支持按时间范围筛选、查看柱状图与趋势图，以及按模型和 API 主机汇总用量。
  - 最近请求明细可展开查看耗时、计数来源及可用的缓存和推理用量信息，支持清空统计记录。
  - 模型配置新增服务端用量开关及本地 Token 预估器选择；新建 DeepSeek 配置默认启用服务端用量。
- **个性化与配置：**
  - 新增跟随系统、浅色、深色三种主题模式。
  - 模型配置支持克隆，方便在保留已有参数的基础上创建配置副本。
  - 新增葡萄牙语（巴西）、意大利语、越南语和印度尼西亚语界面，并补齐已有语言的新功能文案。

#### 🎨 体验优化

- **长对话与上下文：**
  - 单聊、群聊的历史消息改为分页加载，并优化上下文构建与 Token 计算，减少长会话中的重复处理。
  - 新增参与模型请求的历史消息数量设置，默认使用最近 500 条，设为 0 可取消此限制；本地聊天记录不会因此删除。
- **聊天与编辑体验：**
  - 聊天正文支持长按选择和复制文字。
  - 新增列表侧边滚动指示器，支持拖动定位和自动隐藏。
  - 优化聊天输入区、键盘展开与横屏布局，统一世界书快捷管理对话框，并调整世界书条目、模型配置和故事编辑页面。
- **提示与兼容性：**
  - 改善模型未配置、请求失败及摘要额度不足等情况的提示和设置引导。
  - 优化摘要生成失败、空结果和截断结果的处理，避免不完整内容覆盖有效摘要。
  - @Equaraphanus 支持用户安装的系统级 CA 证书，方便连接使用自定义证书链的服务。

#### 🐛 问题修复

- 修复部分横屏页面被系统导航栏遮挡的问题。
- 修复故事导出时，世界书条目过多导致数据库查询失败的问题。

### English Version (英文)

#### ✨ What's New

- **Images in Single and Group Chats:**
  - Send images with text or as image-only messages, with up to four images per new message.
  - Added an image viewer with zoom, double-tap gestures, swipe navigation, thumbnails, and image saving.
  - Choose automatic, original, or custom image processing, with configurable file size and dimension limits.
  - Send images through OpenAI-compatible, Anthropic Messages, and Gemini protocols, with configurable image input capabilities and token estimation strategies.
  - Image costs now participate in context and summary budgets. The Prompt Inspector shows image information and reasons for omission.
  - Add, remove, and reorder images when editing user messages. Existing character and narrator images can be retained, removed, or reordered, while the add-image action remains unavailable for those messages.
- **Chat Image Import and Export:**
  - Single-chat JSONL archives can now include images and restore attachments when imported back into RPClient.
  - Import SillyTavern image messages and select a local resource folder to resolve external image references. Missing images are counted and skipped.
  - Archives support compression and resource deduplication to reduce space used by repeated images.
  - Imported character and narrator images are preserved when creating chat branches.
- **Token Usage Statistics:**
  - Added a usage dashboard showing input, output, total tokens, and successful request counts.
  - Filter by time period, switch between bar and trend charts, and view totals grouped by model and API host.
  - Expand recent requests to inspect duration, counting sources, and available cache and reasoning usage. Usage records can also be cleared.
  - Added a provider-reported usage setting and local tokenizer selection. New DeepSeek configurations enable provider-reported usage by default.
- **Personalization and Configuration:**
  - Choose between system, light, and dark themes.
  - Clone model configurations to create a copy while retaining existing parameters.
  - Added Brazilian Portuguese, Italian, Vietnamese, and Indonesian translations, and updated existing languages for the new features.

#### 🎨 Improvements

- **Long Conversations and Context:**
  - Added paginated history loading and improved context construction and token calculation in single and group chats to reduce repeated processing.
  - Added a prompt history limit, using the latest 500 messages by default. Set it to 0 to disable the limit; stored chat history is not deleted.
- **Chat and Editing Experience:**
  - Long-press message text to select and copy it.
  - Added side scroll indicators with drag navigation and automatic hiding.
  - Refined chat input, keyboard, and landscape layouts; unified quick World Book management dialogs and improved entry, model configuration, and story editing screens.
- **Feedback and Compatibility:**
  - Improved guidance for missing model configurations, failed requests, and insufficient summary budgets.
  - Improved handling of failed, empty, and truncated summary responses to avoid replacing valid summaries with incomplete content.
  - @Equaraphanus Added support for user-installed system CA certificates when connecting to services with custom certificate chains.

#### 🐛 Bug Fixes

- Fixed system navigation bars obscuring some landscape layouts.
- Fixed story export failing when too many World Book entries were included in a database query.
