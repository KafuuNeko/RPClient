## 保持的约束

- `AppDatabase.version = 4`，不新增 `4→5` 迁移；本次剩余实现没有修改既有 schema 和两张消息表。
- 每条消息最多 4 张、单次请求最多 12 张；原图单张最多 32 MiB／4800 万像素；发送长边最多 1536 px、单张最多 2 MiB、完整含图 JSON 最多 16 MiB。
- 图片能力未知允许尝试，明确不支持则拦截；不静默丢图、不自动换模型、不额外发起付费探测。
- 图片 Token 使用统一的保守估算，当前每图回退 4096 Token，并在检查器标为估算；服务端实际用量优先，不能把估算与服务端数据相加。
- 发送版本去除原始元数据，透明图使用 PNG、其他图使用 JPEG；原始字节保留，缓存可以删除重建。
- 请求中 Base64 流式写入临时文件，日志仅保留图片元数据；错误响应与流式日志也脱敏、限制保存长度。
- 图片与所属正文一起裁剪；当前用户图片不能被静默裁掉，超过必需内容预算时明确失败。
- 暂不提供携图归档包、模型输出图片、服务商 Files API 缓存或正文任意位置插图，这些沿用原方案的后续范围。
